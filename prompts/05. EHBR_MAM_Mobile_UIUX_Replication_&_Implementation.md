## 4. Figma-to-Flutter Workflow

For every requested screen or feature:

1. Identify the relevant Figma frame.
2. Inspect its dimensions, layout, content, spacing, components, and interactions.
3. Locate the existing Flutter screen and related widgets.
4. Compare the existing implementation with the approved design.
5. Identify reusable components and existing theme styles.
6. Determine which source files need changes.
7. Identify backend dependencies.
8. Present an implementation plan.
9. Implement the approved changes.
10. Compare the completed screen with the Figma reference.

Pay attention to Android and iOS differences, safe areas, status bars, navigation bars, keyboard behavior, scrolling, and different screen dimensions.
